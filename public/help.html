UI Forger — Ayuda completa

Editor visual de UI/UX offline, agnóstico y multi-destino. Diseña pantallas como en Figma; exporta a HTML, Unity, Unreal, Godot, Lottie y más.

Introducción

UI Forger es un editor visual de interfaz de usuario diseñado específicamente para juegos y aplicaciones multiplataforma. Permite diseñar pantallas completas con componentes reutilizables, estados interactivos, animaciones y exportar directamente a motores de juego.

🎨 Diseño visual

Arrastrar y soltar, snap, guías, reglas, auto-layout flexbox, gradientes, sombras, blend modes.

🧩 Componentes

Crear, instanciar, variantes, props boolean/string, sync automático entre instancias.

🎬 Animación

Timelines con keyframes, easing visual, estados interactivos, preview en vivo.

🎮 Game UI

9-slice, conditional visibility, localization, audio cues, sprite sheets, profiling.

📤 Exportación

HTML/CSS, PNG @1x/2x/3x, Unity, Godot, Unreal, Lottie, tokens DTCG.

📁 Persistencia

Autosave, File System Access API, carpetas de proyecto organizadas.

Primeros pasos

Abrir la app

Al abrir UI Forger por primera vez verás un tour guiado por las zonas del editor. Puedes reabrirlo desde Ayuda → Tour de la app.

Crear un proyecto

  • Archivo → Nuevo proyecto (Cmd/Ctrl+N): elige un tamaño o starter kit.
  • Starter kits: Menú de juego (1080p), HUD móvil, RPG Inventory, FPS HUD, Racing, Platformer, Strategy.

Guardar

  • Cmd/Ctrl+S: guarda como .canvas.
  • Archivo → Guardar como…: File System Access API (Chrome/Edge).
  • Archivo → 💾 Guardar en carpeta: guarda en la carpeta del proyecto.
  • Autosave: cada 3 segundos en localStorage.

Selección y movimiento

Selección

  • Clic: selecciona un nodo.
  • Shift+clic: añade/quita de la selección.
  • Marquee: arrastrar en vacío selecciona nodos tocados (incluye hijos anidados).
  • Cmd+A: seleccionar todo.
  • Esc: deseleccionar.

Mover

  • Flechas: nudge 1px. Shift+flechas: 10px.
  • Shift durante drag: restringir al eje dominante.
  • Snap: guías rojas de alineación + spacing hints.
  • [ / ]: mover capa atrás/adelante.

Redimensionar

Selecciona un nodo → 8 handles aparecen. Arrastra para redimensionar.

Formas y texto

Formas

Rectángulo (R), Elipse (O), Línea (L). Todas editables en el Inspector: color, borde, radios, sombra, opacidad.

Texto

  • T + clic = crear texto.
  • Doble clic = editar inline.
  • Inspector: familia, peso, tamaño, tracking, line-height, alineación.
  • Localización: define una clave de localización (ej: ui.hp_label) en el panel 🎮.

Imágenes

Arrastra .jpg, .png, .webp al lienzo. Inspector: ajuste cover/contain/fill.

Vectores (SVG)

Arrastra un .svg al lienzo → nodo vector editable con path SVG.

Componentes

Crear

Selecciona un nodo → Crear componente (o Cmd+Shift+C). Aparece en la pestaña Diseño → Librería.

Insertar

En Diseño → Librería, clic en un componente → se inserta en el centro del lienzo.

Variantes

Selecciona componente → Añadir variante (ej: "Primary", "Secondary", "Danger").

Component Sync NEW

  • ↑ Push al padre: empuja los cambios de una instancia al componente padre.
  • ↓ Pull del padre: actualiza una instancia desde el componente padre.
  • Auto-sync: al hacer push, TODAS las instancias se actualizan.
  • Botones en el Inspector bajo "🔄 Sync de componente".

Props

Los componentes pueden definir props boolean/string. Las instancias muestran overrides en el Inspector.

Estados interactivos

Define cómo se ve un nodo en diferentes estados: Hover, Pressed, Disabled, Focused.

  • Configura overrides de estilo por estado.
  • Transición: duración (ms) + curva de easing.
  • Preview en vivo en modo Preview.

Animación

Timelines

  • Pestaña Animar → Crear línea de tiempo.
  • Selecciona nodo → Capturar keyframe en el instante deseado.
  • Reproduce con ▶ (Web Animations API).

Editor de easing

Gráfica con puntos de control arrastrables (estilo After Effects). Presets: Lineal, Entrada, Salida, Resorte, Brusco.

Prototipado

  • Crea pantallas adicionales (pestaña Prototipo).
  • Conecta nodos a pantallas con transición (fade, slide, zoom).
  • Preview con ▶ → pulsa nodos conectados para navegar.
  • Exportador HTML reproduce el flujo completo.

Constraints (Responsive)

Cada nodo decide cómo reacciona al cambiar el tamaño de su pantalla:

  • Fijo a la izquierda/derecha/arriba/abajo.
  • Centrado.
  • Estirar (stretch).
  • Escalar (scale).

Exportador HTML emite CSS responsive real. Unity/Unreal mapea a Anchors nativos.

Temas múltiples

Crea variantes de color (light/dark/…). Cada tema guarda su paleta. Export de tokens incluye DTCG + CSS por tema.

Carpeta del proyecto NEW

Los exports se guardan en una carpeta organizada en vez de descargar:

  • Archivo → 📁 Elegir carpeta del proyecto…: abre Directory Picker.
  • Archivo → 💾 Guardar en carpeta: guarda el .canvas.
  • Todos los exports van a subcarpetas (exports/unity/, exports/godot/, etc.).
💡 Si no eliges carpeta, los exports siguen descargándose como antes (fallback).

Anotaciones de review

  • Modo anotar: clic en la pantalla → pin numerado.
  • Escribe la nota en el panel Prototipo.
  • Marca como resuelta ✓ o bórrala.
  • Comments thread NEW: panel de comentarios con threading.

🎮 Game UI Features

9-Slice Scaling GAME

Define zonas de borde que se estiran sin deformar (botones, paneles, tooltips):

  • Panel 🎮 → 9-Slice Scaling → Activar.
  • Configura pixeles de cada borde (top, right, bottom, left).
  • Se renderiza con CSS border-image-slice.

Visibilidad condicional GAME

El nodo solo se muestra si se cumplen condiciones de variables de juego:

  • Panel 🎮 → Variables de juego: define variables (bool/num/str).
  • Panel 🎮 → Visibilidad condicional: añade reglas (==, !=, truthy, etc.).
  • En preview, cambia las variables para ver los nodos aparecer/desaparecer.

Localización GAME

Define claves de localización para textos:

  • Selecciona nodo de texto → Panel 🎮 → Localización.
  • Escribe la clave (ej: ui.hp_label).
  • En canvas se muestra como {ui.hp_label}.
  • El exportador HTML usa la clave como contenido del elemento.

Audio Cues GAME

Asocia sonidos a eventos de interacción:

  • Panel 🎮 → Audio Cues.
  • Eventos: Hover, Press, Release, Open, Close.
  • Escribe el nombre del sonido para cada evento.

Sprite Sheets GAME

Importa y anima sprite sheets frame-by-frame:

  • Define en el IR: spriteSheet: { src, frameWidth, frameHeight, fps, loop }.
  • El renderer reproduce los frames automáticamente en el canvas.

Multi-resolución GAME

Preview del diseño en múltiples resoluciones simultáneamente:

  • 7 presets: 720p, 1080p, 4K, Ultrawide, iPhone 14, Android, Web.
  • Clic en un preset → redimensiona el root a esa resolución.
  • Multi-res preview panel con miniaturas de cada resolución.

Overrides por plataforma GAME

Define estilos diferentes por plataforma:

  • Selector en TopBar: 📱 (mobile), 🎮 (console), 🖥️ (PC), 🌐 (web).
  • Activa una plataforma → los overrides se aplican en tiempo real.
  • En el Inspector, cada campo de estilo tiene botón de plataforma para definir el override.

Profiling overlay GAME

Métricas de rendimiento en vivo en el canvas:

  • Nodos: total y hojas.
  • Profundidad: niveles de anidamiento.
  • Draw calls estimados: basado en nodos con sombras, gradientes, imágenes, opacidad.
  • Fill rate: área pintada vs área de pantalla.
  • Grado: 🟢 Excelente (<50), 🟡 Bueno (<150), 🔴 Pesado (>150).

⚡ Funciones avanzadas

Component Sync PRO

Mantén tus componentes sincronizados entre definición e instancias:

  • ↑ Push al padre: edita una instancia → push al componente → TODAS las instancias se actualizan.
  • ↓ Pull del padre: actualiza una instancia desde la definición del componente.
  • El sync respeta los overrides de posición (x, y) de cada instancia.

Copy/Paste entre pantallas PRO

  • Cmd+C: copia los nodos seleccionados (deep clone + remap IDs).
  • Cmd+V: pega en la pantalla actual con offset automático (20px).
  • Funciona entre pantallas del prototipo.

Snapshots PRO

  • Cmd+Shift+S: guarda un snapshot nombrado del estado actual.
  • Panel de snapshots: restaura cualquier versión anterior.
  • Los snapshots incluyen el documento completo (tokens, componentes, pantallas).

Tema del canvas PRO

  • Selector 🌙/☀️ en la barra de herramientas.
  • Oscuro: fondo #0B0E1A (default).
  • Claro: fondo #f0f0f0 (para diseñar UI de apps móviles).

Comentarios PRO

  • Panel de comentarios con threading (estilo Figma).
  • Marcar como resuelto/pendiente.
  • Textarea para editar el texto del comentario.
