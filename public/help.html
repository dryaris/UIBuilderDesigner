UI Forger — Guía completa

Editor visual de UI/UX offline, agnóstico y multi-destino. Diseña pantallas como en Figma; exporta a HTML, Unity, Unreal, Godot, Lottie y más.

Plataformas: Web (navegador) · Windows · macOS · Linux · v0.2.2

Primeros pasos

Abrir la app

Al abrir UI Forger verás el editor completo. Puedes crear un proyecto nuevo o abrir uno existente.

Crear un proyecto

  • Archivo → Nuevo proyecto (o Cmd/Ctrl+N): elige un tamaño de pantalla o usa un starter kit pre-diseñado
  • Starter kits disponibles: RPG Inventory ⚔️, FPS HUD 🔫, Racing 🏎️, Platformer 🍄, Strategy 🏰, Menú de juego, HUD móvil

Abrir un proyecto existente

  • Archivo → Abrir .canvas (o Cmd/Ctrl+Shift+O): selecciona un archivo .canvas (ZIP)
  • Archivo → Abrir archivo…: abre directamente desde la carpeta del proyecto (File System Access API)

Guardar

  • Cmd/Ctrl+S: guarda el proyecto como .canvas
  • Archivo → Guardar en carpeta: guarda en la carpeta del proyecto seleccionada
  • Autosave: la app guarda automáticamente cada 3 segundos en localStorage
💡 Carpeta del proyecto: Selecciona una carpeta con Archivo → Elegir carpeta del proyecto… y todos los exports se guardarán automáticamente en subcarpetas organizadas.

Reglas y guías

  • Las reglas aparecen en la parte superior e izquierda del lienzo
  • Arrastra desde una regla para crear una guía (línea de referencia magnética)
  • Las guías se pegan a nodos al arrastrar (snapping)
  • Arrastra una guía fuera del lienzo para borrarla

Mini-map Nuevo

En la esquina inferior izquierda del canvas aparece un mini-map con vista de pájaro. Muestra todos los screens como rects proporcionales con el viewport actual dibujado en azul. Haz clic para navegar rápidamente.

Modo outline (wireframe) Nuevo

Cmd/Ctrl+Y alterna entre vista normal y modo outline (solo bordes, sin fills) para ver la estructura del diseño.

Selección y movimiento

Selección

  • Clic: selecciona un nodo
  • Shift + clic: añade/quita de la selección (multi-selección)
  • Arrastrar en vacío (marquee): selecciona todos los nodos que toca el rectángulo (incluye hijos anidados)
  • Cmd/Ctrl+A: seleccionar todos los nodos
  • Esc: deseleccionar todo

Mover

  • Arrastra un nodo seleccionado: se mueve con pixel-snap
  • Flechas: nudge 1px
  • Shift + flechas: nudge 10px
  • Al mover aparecen guías de snap y spacing hints (distancias exactas en px)
  • Shift durante el arrastre: restringe al eje dominante

Redimensionar

  • Selecciona un nodo → aparecen 8 handles
  • Arrastra un handle para redimensionar
  • Shift + handle: mantiene la proporción

Medición de distancias (Alt) Nuevo

Mantén Alt y haz hover sobre un nodo para ver las distancias exactas (en px) entre la selección y el hover, con líneas punteadas y ticks — como Figma.

Formas y texto

Formas

Rectángulo, elipse, línea — todas editables en el Inspector: color, borde, esquinas redondeadas, sombra, opacidad.

Texto

  • Doble clic en un nodo de texto: editar inline en el lienzo
  • En el Inspector: familia, peso, tamaño, tracking, line-height, alineación, transform
  • Autosize: el texto se ajusta al contenido

Vectores (SVG)

Arrastra un archivo .svg al lienzo o Archivo → Importar SVG: se importa como nodo vector editable (paths, gradientes, transformaciones).

Copy/Paste entre pantallas Nuevo

  • Cmd/Ctrl+C: copia nodos completos
  • Cmd/Ctrl+V: pega con offset automático en la pantalla activa
  • Cmd/Ctrl+Shift+C: copiar estilo
  • Cmd/Ctrl+Shift+V: pegar estilo (fill, stroke, shadow, radius)

Estilos visuales

Color

Selecciona un nodo → chip de color en el Inspector. Color picker con HEX/RGB/HSL. Guardar como token con un clic.

Gradientes

Cambia el tipo de relleno a Lineal o Radial. Configura ángulo y paradas de color.

Sombras

Drop shadow y inner shadow con offsetX, offsetY, blur, spread, color, inset. Múltiples sombras apilables.

Bordes y radios

Stroke: ancho, color, estilo. Border radius: individual o uniforme.

Mezcla y filtros

Blend modes (multiply, screen, overlay, etc.). Blur: desenfoque gaussiano.

Tamaño porcentual Nuevo

En el Inspector → Tamaño, el botón "%" permite definir ancho/alto como porcentaje del padre (0–200%).

Editor de easing visual

Cada curva de easing es una gráfica con dos puntos de control arrastrables (estilo After Effects), presets de un clic (Lineal, Entrada, Salida, Resorte, Brusco) y un botón Probar.

Exportar tokens

Archivo → Exportar tokens: ZIP con tokens.json (W3C DTCG), tokens.css (custom properties) y proyecto Style Dictionary.

Componentes

Crear un componente

  1. Selecciona un nodo (o varios → se agrupan)
  2. Clic derecho → Crear componente (o Cmd/Ctrl+Shift+C)
  3. Aparece en la pestaña Diseño → Librería

Insertar una instancia

En la pestaña Diseño → Librería, haz clic en un componente → se inserta en el centro del lienzo.

Variantes

Selecciona un componente → Clic derecho → Añadir variante (ej: "Primary", "Secondary", "Danger").

Props boolean/string Pro

En Diseño → Librería → Props, define props personalizables. Las instancias muestran overrides en el Inspector.

Sync bidireccional Nuevo

  • Push ↑: actualiza la definición del componente desde una instancia
  • Pull ↓: aplica los cambios de la definición a todas las instancias
  • Auto-sync: al editar el componente padre, todas las instancias se actualizan en vivo

Animación (timelines y keyframes)

Crear una línea de tiempo

Pestaña Animar → "Crear línea de tiempo" → escribe un nombre.

Capturar keyframes

  1. Selecciona un nodo
  2. Mueve el cursor de tiempo al instante deseado
  3. Haz clic en Capturar keyframe
  4. Repite para otros instantes y nodos

Reproducir

▶ reproduce la animación en el lienzo (Web Animations API). Loop opcional.

Export Lottie

Archivo → Exportar Lottie: JSON Bodymovin con keyframes de posición, opacidad, escala, color, tamaño, rotación y easing por tramo.

Prototipado entre pantallas

Crear pantallas

Pestaña Prototipo → "Nueva pantalla" o "Duplicar pantalla".

Conectar pantallas

  1. Selecciona un nodo en el lienzo
  2. Haz clic en "Conectar a..." → elige la pantalla destino
  3. Configura la transición: tipo (Fade, Slide, Zoom), duración (ms) + curva de easing

Previsualizar

Modo Preview (▶): pulsa un nodo conectado → navega a su pantalla con la transición configurada.

Anotaciones de review

Modo anotar → clic en la pantalla → pin numerado → escribe la nota → marca como resuelta ✓ o bórrala.

Tema del editor

  • Tema claro/oscuro: selector 🌙/☀️ en la barra de herramientas
  • Fondo del canvas: configurable (gris claro, oscuro, cuadrícula)
  • Reglas: activa/desactiva desde la barra de herramientas

Game UI Game

9-Slice / 9-Patch

Permite estirar imágenes de UI sin deformar bordes. Configura los insets (top/right/bottom/left) en el Inspector → sección 9-Slice. El canvas renderiza con border-image-slice CSS. Ideal para botones, paneles y tooltips de juego.

Anchoring + Pivot

Cada nodo puede tener un anchor (left/center/right/stretch × top/center/bottom/stretch) y un pivot (origen de rotación/escala). Esto determina cómo se posiciona el nodo dentro de su padre y cómo reacciona al redimensionar.

Visibilidad condicional

Define reglas basadas en variables de juego (strings, números, booleanos). Si todas las reglas se cumplen, el nodo se muestra; si no, se oculta. Útil para: mostrar/ocultar UI según el estado del juego.

Localización

Asigna una localizationKey a nodos de texto. En el canvas se muestra {key}. El exportador incluye un placeholder listo para ser reemplazado por el sistema de localización del motor.

Audio Cues

Asigna eventos de sonido a nodos: onHover, onPress, onFocus, onDisable. Se exportan como metadata para el motor de juego.

Sprite Sheets

Define un sprite sheet con: URL de la imagen, columnas/filas, y FPS. El canvas renderiza un preview de la animación con background-position CSS.

Multi-resolución

Preview flotante con 7 presets: 720p, 1080p, 4K, ultrawide, iPhone, Android, Web. Haz clic en uno para redimensionar la pantalla raíz y ver cómo se adapta.

Plataformas

Selector en TopBar: 📱 Mobile, 🎮 Console, 🖥️ PC, 🌐 Web. Activa overrides específicos por plataforma (distintos tamaños, anchoring, safe areas).

Profiling Overlay

Muestra en vivo: draw calls estimados, número de nodos, profundidad del árbol, y un grade (🟢 bien / 🟡 aceptable / 🔴 problemas). Útil para optimizar pantallas complejas.

Templates por género

Al crear un proyecto nuevo, puedes elegir un template predefinido: RPG Inventory ⚔️, FPS HUD 🔫, Racing 🏎️, Platformer 🍄, Strategy 🏰. Incluyen nodos listos para editar.

Avanzado

Sync de componentes

Al editar una instancia, el Inspector muestra botones de Push ↑ (actualizar definición) y Pull ↓ (aplicar cambios a todas las instancias). Auto-sync mantiene todo consistente.

Copy/Paste entre pantallas

Cmd/Ctrl+C copia nodos completos. Cmd/Ctrl+V los pega en la pantalla activa con offset automático. Funciona entre pantallas diferentes del mismo proyecto.

Snapshots versionados

Cmd/Ctrl+Shift+S guarda un snapshot nombrado del estado actual. El panel de snapshots permite ver todos los guardados y restaurar cualquiera.

Tema del canvas

Selector 🌙/☀️ en TopBar: cambia entre fondo oscuro (por defecto) y fondo claro para ver la UI sobre diferentes superficies.

Comentarios

Panel de comentarios con threading: comenta en nodos específicos, resuelve discusiones, marca como resolved/unresolved. Útil para revisión con equipo.

Carpeta del proyecto

Archivo → Elegir carpeta del proyecto… selecciona una carpeta (se crea si no existe). Todos los exports se guardan automáticamente en subcarpetas organizadas.

GPU y rendimiento

⚠️ GPUs NVIDIA: En PCs con NVIDIA (especialmente RTX 3050/3060 laptop, drivers < v535), la app puede no cargar (pantalla negra). Ver sección de solución de problemas abajo.

Detección automática

La app detecta GPUs NVIDIA automáticamente y activa software rendering como fallback. Si la app carga pero el rendimiento es bajo, prueba:

  • Actualizar drivers NVIDIA a versión 535+
  • NVIDIA Control Panel → Preferencia de procesamiento gráfico → Integrada
  • Variable de entorno: UIFORGER_DISABLE_GPU=1

Solución de problemas

Pantalla negra (GPUs NVIDIA)

PCs afectadas conocidas: i5 10ª gen + 16GB RAM + RTX 3050 Laptop + Windows 10 Home
  1. Actualizar drivers NVIDIA a versión 535+ desde nvidia.com/drivers
  2. NVIDIA Control Panel → Configuración 3D → "Preferencia de procesamiento gráfico" → "Integrada"
  3. Variable de entorno: UIFORGER_DISABLE_GPU=1
  4. Chrome con flags: chrome --disable-gpu --disable-gpu-compositing

La app no carga

  • Verifica que el navegador soporta File System Access API (Chrome/Edge 86+)
  • Limpia localStorage del dominio e intenta de nuevo
  • Abre la consola del navegador (F12) para ver errores

Los exports no se guardan

  • Verifica que seleccionaste una carpeta de proyecto (Archivo → Elegir carpeta)
  • En Firefox/Safari, los exports se descargan (File System Access API no disponible)
